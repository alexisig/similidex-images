# Similidex — images des produits

Photos de face des similis végétaux, en WebP 400 px, utilisées par l'app Similidex.

```
https://alexisig.github.io/similidex-images/img/<code-barres>.webp
```

`manifest.json` liste les codes-barres disponibles et la version de chaque photo.
